# AI School Quest

**Игровой AI-репетитор для школьников 5 класса** — демонстрационный веб-MVP: выбор предмета, героя-наставника, режима урока и учебный чат в стиле квеста. Работает полностью в браузере, без backend и без внешних API.

**Стек:** HTML5 · CSS3 · JavaScript (ванильный, без фреймворков и CDN).

---

## О проекте

**AI School Quest** — это прототип сервиса для родителей и педагогов: ребёнок проходит короткий онбординг, выбирает предмет и наставника, затем общается с «AI-репетитором». Ответы наставника в демо **имитируются** через JavaScript (без реального подключения к нейросети).

---

## Что умеет приложение

| Возможность | Описание |
|-------------|----------|
| **Онбординг** | Имя ученика, класс, цель обучения (домашка, контрольная, подтянуть знания, игра) |
| **Предметы и герои** | Шесть предметов с уникальными героями-наставниками |
| **Режимы урока** | Квест, тест, «простыми словами», помощь с домашкой — разный стиль ответов |
| **Чат** | Сообщения ученика и наставника, XP, уровень, медали, ежедневные цели |
| **Родителям** | Краткий отчёт после активности, режим родителя с аналитикой и планом на 7 дней |
| **Сохранение** | Прогресс в `localStorage` (локально на устройстве) |
| **Демо для клиентов** | Блок с заявкой и информацией об авторе проекта |

## Как запустить проект

Требуется только современный браузер. Внешние библиотеки не используются.

### Вариант 1: открыть файл напрямую

1. Скачайте или клонируйте репозиторий.  
2. Откройте в браузере файл **`index.html`**.

### Вариант 2: локальный сервер (рекомендуется для единообразия)

Из папки проекта, например:

```bash
# Python 3
python -m http.server 8080
```

Затем в браузере откройте: `http://localhost:8080`

Структура репозитория:

```
├── index.html    # разметка и экраны приложения
├── style.css     # стили
├── script.js     # логика и имитация ответов
└── README.md     # документация
```
